## 一句话概括

一个叫 REA 的开源 MCP 工具把 Ghidra/Hopper/IDA 等反编译工具接进 AI Agent，让你指着任何商业软件说「这个功能我要了」，Agent 就去翻它的二进制并给出重构实现——新智元据此宣称闭源护城河破产。

## 核心要点

- **REA 是什么**：`npx rea-agents setup` 一条命令，把 REA 注册成 Agent 的 MCP 服务器，之后 Claude Code / Codex / Cursor / Gemini CLI 等就能调用它去反编译、读汇编、追接口，最后用人类语言汇报「它是这么干的」并给出重构代码。
- **覆盖的目标类型远超「二进制」**：原生二进制、ELF 布局、EVM 字节码、记录的 Linux crash、JS/Electron 应用、网站、HAR 网络抓包、.NET 程序集、Android APK 与真机（adb）、JEB 工程、固件（binwalk/unblob）、Apple bundle、进程行为——共十几类，每类都标明依赖什么外部工具。
- **它不是反编译器，是编排层**：深度原生分析要靠你本地已装的 Hopper / Ghidra / IDA；JS 与 .NET 的静态分析不需要任何本地引擎。REA 做的是「把专业工具变成 Agent 能调用的接口 + 把取证流程固化 + 把证据回传」。
- **作者的叙事**：代码层面的微创新会死，抄袭变成自动化科学；IP 律师集体心梗（AI 复刻的代码逻辑一致但语法全换，法官没法判）；未来软件工程沦为比拼谁的代码混淆得更恶心的「反人类竞赛」。
- **结论句**：「在 REA 诞生之后，这世界上所有的软件生意都只关乎算力、数据和网络效应，除了代码本身。代码不再神圣，只是一堆随时可以被逆向的耗材。」

## 金句

> 这世界上所有的事物都关乎性，除了性本身。在 REA 诞生之后，这世界上所有的软件生意都只关乎算力、数据和网络效应，除了代码本身。

> 我们将进入一个极其滑稽的时代：AI 在努力把屎还原成佳肴，而人类工程师在拼命把佳肴重新做成屎。

## 质疑与核查

**（实测于 2026-10-11 13:25，GitHub API + npm registry + README 原文）**

1. ✅ **项目真实存在**：`github.com/morluto/rea`，MIT 协议，TypeScript，实测 **77,724 stars / 16,654 forks**，npm 包名 `rea-agents`。这条不是吹的。
2. ❌ **「一天登顶」严重失实**：仓库 `created_at = 2026-04-14`，已存在近 6 个月；npm 版本号已到 **v6.4.0**（10-11 03:58 发布），10-08 v6.0.0 → 10-11 v6.4.0 三天发了五个版本。**这是成熟项目在第 6 个大版本阶段的突然爆发，不是一天冒出来的新项目。**「一天登顶 GitHub Trending 榜首」和「一天诞生」是两件事，标题把前者写成了后者。
3. ⚠️ **star 数自相矛盾**：正文前面说「近 7 万颗星」，后面说「第三天已经接近 8 万颗星」，同一篇里两个数。实测 77,724，两者都对不上对方。
4. ❌ **「已经在努力逆向 Office」「若真能完整逆向 macOS/iOS」——官方 showcase 里根本没有 Office**。已公布的三个案例是：DX-Ball（DOS 游戏的声音 pan 计算）、Notion（Electron 剪贴板桥）、TH04（PC-98 16-bit 弹幕环）。**全是几十年前的古早软件或 Electron 应用**，与「大型商业软件」「闭源操作系统」差了几个数量级。这是全篇最大的一次拔高。
5. ⚠️ **归因错位**：「把汇编代码嚼碎」的真正技术在 Ghidra / Hopper / IDA / JADX 里，这些工具几十年前就有了。REA 的贡献是**接口化 + 取证流程 + 证据回传**，不是破解能力本身。把它说成「AI 把二进制扒光」，等于把 MCP 协议的功劳算给了模型。
6. ⭐ **报道漏掉了最有价值的一条设计原则**（README 原文）：*「results include the evidence and limitations behind each conclusion」*——**每个结论都强制附带支撑它的证据、以及它的局限**。这在 hype 稿里不起眼，但它恰恰是「AI 取证能不能信」这个问题的答案形式：**可核查的是证据链，不是结论**。
7. ⭐ **报道也漏掉了最有说服力的一条数字**：DX-Ball 案例里重构出的 C 代码，**通过了 3,205 个原始 x86 用例，并逐字节复现了 63 字节的编译产物**。这才是「逆向正确」该有的验收口径——比 star 数有意义得多，也与「可复现性」那条纪律同源。
8. ⚠️ **对比数据不可核**：「Jev 前三天下载 3.5 万次」「REA 累计约 4.4 万次」——Jev 是闭源产品，npm 上的 `jev` 是 2021 年的无关空包（0.0.0），**该数字无公开来源**。REA 侧可核的是 npm 官方统计：rea-agents 上周（10-03~10-09）**39,279 次**下载，与「4.4 万累计」口径不同，无法直接对比。
9. ⚠️ **信源权重**：作者 `morluto` 的 GitHub bio 只有一句 "member of technically staff"，X @morluto，2020 年注册，252 个公开仓库，**无机构背书**。对照同日剪藏的 Quantum-Harbor（NUS CQT 学术团队、arXiv 可查、有对照实验），两者权重不在一个量级——**可以拿来当产业信号，不能拿来当技术结论的引用**。
10. ⚠️ **「混淆竞赛」那段是纯推演**：没有任何数据支持「未来程序员会主动写烂代码」，它只是作者的逻辑外推。当作一个可能的产业反应记下即可，别当成预测。
