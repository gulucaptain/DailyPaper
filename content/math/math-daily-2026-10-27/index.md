### The boosted loop-erased random walk

{{< paper-meta
  authors="Gefei Cai、Xinyi Li、Daisuke Shiraishi、Aoteng Xia"
  source="arXiv 预印本"
  date="2026-10-23 · v1"
  arxiv="2610.32821"
  fulltext="https://arxiv.org/html/2610.32821v1"
  fulltextLabel="全文 v1"
  directions="自相互作用随机游走"
>}}

**研究问题与背景：** 普通擦环随机游走（LERW）按时间顺序删除随机游走产生的回路。本文先增加长随机游走的权重，再擦环，研究这种近临界扰动能否得到自然参数下的连续极限，以及它与原始极限曲线之间的关系。

**核心模型与数学设定：** 在 {{< math >}}d\in\{2,3\}{{< /math >}} 的单位球 {{< math >}}D=B(0,1){{< /math >}} 中，从原点出发的网格随机游走在首次离开区域时停止，出口不预先指定。网格为 {{< math >}}\delta{{< /math >}}，boost 参数为 {{< math >}}m\ge0{{< /math >}}，每条路径的权重是

{{< math display="true" >}}
\left(\frac{1+m^2\delta^2}{2d}\right)^{|\omega|}.
{{< /math >}}

每个底层游走步的时间为 {{< math >}}\delta^2{{< /math >}}，对应 Brownian 生成元 {{< math >}}\Delta/(2d){{< /math >}}。当整个底层游走的配分函数发散时，作者通过删除路径无关的回路质量，定义延伸的擦环模型；不能在这个区域继续假装底层加权游走本身已归一化。

**主要定理或理论结果：** **定理1.2**对每个有限 {{< math >}}m{{< /math >}} 构造二维、三维自然参数下的标度极限。极限律 {{< math >}}\mathbb P^{(m)}{{< /math >}} 始终对普通 LERW 极限律 {{< math >}}\mathbb P{{< /math >}} 绝对连续；其密度的正性由路径迹 {{< math >}}K{{< /math >}} 补域的最低 Dirichlet 特征值控制。

**推论1.4**给出反向绝对连续成立的精确条件：

{{< math display="true" >}}
\begin{gathered}
d=2:\quad \mathbb P\ll\mathbb P^{(m)}
\ \Longleftrightarrow\ m^2\le\pi^2/4,\\
d=3:\quad \mathbb P\ll\mathbb P^{(m)}
\ \Longleftrightarrow\ m^2\le\lambda_1(D).
\end{gathered}
{{< /math >}}

这里 {{< math >}}\lambda_1{{< /math >}} 对应上述生成元，阈值含等号。超过阈值失去的是**相互**绝对连续，单向关系仍在，不能写成两种律相互奇异。

**推论1.5**进一步表明，每个未被曲线访问的开立方体，其边长严格小于 {{< math >}}\pi/(\sqrt2m){{< /math >}}（{{< math >}}m>0{{< /math >}}）。因此增大 boost 会消除宏观空洞；但每个有限 boost 下，Hausdorff 维数仍与普通极限相同，二维为 {{< math >}}5/4{{< /math >}}。这不等于有限参数时曲线已成为通常意义的空间填充曲线。

**方法与证明思路：** 利用随机游走回路测度写出改变权重后的密度。先移除与曲线无关的整域质量，再对短回路与长回路分别归一化：短回路处理小时间发散，长回路由补域谱控制。结合回路与曲线相交的稳定性和自然参数的估计，将离散密度传递到连续极限。**定理1.3**还在 {{< math >}}m^2<\lambda_1(D){{< /math >}} 时给出更直接的 Brownian 回路倾斜表达。

**与研究主线的关联：** 擦环后的路径记录整个过去的几何，属于具有强路径约束的非马尔可夫游走。本文说明，改变底层长度偏好可以明显改变宏观形态，同时保留有限参数下的局部分形维数。

**值得进一步研究的问题：** **本期提出：** 一般区域中的反向绝对连续阈值，能否同样由随机补域谱的本质下确界刻画？研究时应将这一路径相关阈值与底层加权游走的谱阈值分开，而不是沿用单位圆盘的数值。

### The Martingale Property in Volterra Volatility Models

{{< paper-meta
  authors="Julien Guyon、Thibault Jeannin、Benjamin Jourdain"
  source="arXiv 预印本"
  date="2026-10-23 · v1"
  arxiv="2610.32684"
  fulltext="https://arxiv.org/html/2610.32684v1"
  fulltextLabel="全文 v1"
  directions="非马尔可夫过程"
>}}

**研究问题与背景：** 一个非负随机指数即使是局部鞅，也可能损失期望。Volterra 模型的难点在于：换测度后，历史因子的反馈能否把系统推向爆炸？本文将真鞅与严格局部鞅判据放在统一的历史依赖框架内。

**核心模型与数学设定：** 价格过程满足 {{< math >}}dS_t/S_t=\sigma(t,X_t)\,dW_t^\rho{{< /math >}}，{{< math >}}S_0>0{{< /math >}}，其中

{{< math display="true" >}}
\begin{gathered}
W^\rho=\rho W+\sqrt{1-\rho^2}\,W^\perp,\\
X_t=\beta(t)+F_1(Y_{1,t})+F_2(Y_{2,t}),\\
Y_{1,t}=G_1(t)+\int_0^t K_1(t-s)\Gamma_1(s,X_s)\,dW_s,\\
Y_{2,t}=G_2(t)+\int_0^t K_2(t-s)\Gamma_2(s,X_s)\,ds.
\end{gathered}
{{< /math >}}

{{< math >}}W^\perp{{< /math >}} 独立于因子系统；初始曲线 {{< math >}}G_i{{< /math >}} 可携带零时刻之前的历史。论断先在给定初始历史的条件律下表述；转回原概率律时，原文另要求 {{< math >}}\mathbb E S_0<\infty{{< /math >}}。

**主要定理或理论结果：** **定理1的 A 部分**在假设2的适定性条件下证明：{{< math >}}\rho=0{{< /math >}} 时价格是真鞅。这里假设2包括原系统有全局连续、分布唯一的解，以及从有界停止时刻启动的 Girsanov 倾斜系统在爆炸前存在连续解并满足相应条件分布唯一性；不能只写“驱动独立即可”。

对于 {{< math >}}\rho\ne0{{< /math >}}，**定理1的 B 部分**还要求假设1：非负卷积核的积分严格正；随机积分核具有局部 {{< math >}}L^2{{< /math >}} 增量控制，时间积分核具有局部 {{< math >}}L^1{{< /math >}} 增量控制；系数连续并满足原文规定的多项式增长及尾部符号、双边幂次比较。随后提供两条充分路线：

- **(B.i)：** 满足假设3.1，系统不能进入指定爆炸方向，且相反方向漂移有相应增长控制。
- **(B.ii)：** 满足假设3.2的单侧 Girsanov 漂移增长界，并满足假设4.1：{{< math >}}K_1{{< /math >}} 具有形如非负原子加非负、非增局部可积密度的第一类预解式。

这些是带结构假设的充分判据，不是对任意 Volterra 模型的无条件分类。原文**定理2**另给出严格局部鞅的充分条件，其爆炸论证要求更强的光滑核假设4.2：{{< math >}}K_1(0)>0{{< /math >}}、{{< math >}}K_1\in C^1{{< /math >}} 且导数局部有界变差，还需假设5的增长与可达性条件；本期不将其推广为粗糙核下的结论。

**方法与证明思路：** 对停止后的随机指数实施 Girsanov 变换，第一因子获得一个卷积漂移，其被积项为 {{< math >}}\rho\Gamma_1\sigma{{< /math >}}。判定它是否推动系统进入爆炸方向，再用停止、增长控制和 Volterra 预解式估计排除期望损失。严格局部鞅部分则反过来构造正概率爆炸的反馈机制。

**与研究主线的关联：** 记忆核决定过去如何参与当前反馈，也决定可用的非爆炸估计。这是非马尔可夫系统中“解存在”之后的另一个问题：随机指数是否保持期望。

**值得进一步研究的问题：** **本期提出：** 能否降低严格局部鞅判据对核在零点的光滑性要求，使爆炸机制也能覆盖奇异粗糙核？在此之前，应分别记录真鞅判据和爆炸判据的核条件。

### Rough path lifts of multifractional Brownian motions

{{< paper-meta
  authors="Nobuaki Naganuma"
  source="arXiv 预印本"
  date="2026-10-23 · v1"
  arxiv="2610.32201"
  fulltext="https://arxiv.org/html/2610.32201v1"
  fulltextLabel="全文 v1"
  directions="非马尔可夫过程"
>}}

**研究问题与背景：** 分数布朗运动的 Hurst 参数通常固定；multifractional Brownian motion（mBm）允许局部粗糙度随时间变化。只知道轨道连续还不足以定义粗糙积分，必须同时构造迭代积分所组成的几何提升。

**核心模型与数学设定：** 原文定义2.1采用调和表示高斯场 {{< math >}}X(t,v){{< /math >}}，再令 {{< math >}}B(t)=X(t,h(t)){{< /math >}}。Hurst 函数 {{< math >}}h:\mathbb R\to(0,1){{< /math >}} 是确定性的 {{< math >}}C^1{{< /math >}} 函数；多维分量彼此独立，可以具有不同的 {{< math >}}h^\alpha{{< /math >}}。在原文考虑的紧时间区间 {{< math >}}I{{< /math >}} 上，定义

{{< math display="true" >}}
\lambda_* =\min_{1\le\alpha\le d}\inf_{t\in I}h^\alpha(t).
{{< /math >}}

**主要定理或理论结果：** **定理2.9**要求 {{< math >}}\lambda_*>1/4{{< /math >}}。任取

{{< math display="true" >}}
\begin{gathered}
1/4<\lambda<\min(1/2,\lambda_*),\\
1/\lambda<p<\lfloor1/\lambda\rfloor+1,
\end{gathered}
{{< /math >}}

即可构造与该 mBm 相联系的几何 {{< math >}}p{{< /math >}} 变差粗糙路径。这里的 {{< math >}}1/4{{< /math >}} 是本文提升定理的严格下界；定理没有处理等号，也不允许把 {{< math >}}C^1{{< /math >}} 条件替换为任意连续 Hurst 函数。提升为研究 mBm 驱动方程提供输入，但并未自动解决任意不规则系数方程的适定性。

**方法与证明思路：** 利用 Lemarié–Meyer 正交小波基展开，把过程分为满足 Coutin–Qian 协方差增量条件的高频部分，以及具有连续导数的余项。**引理2.8**为高频部分提供提升所需的估计；多维高频过程先获得几何提升，再通过有限变差平移加入光滑余项。这个分解绕开了直接处理复杂时变协方差的困难。

**与研究主线的关联：** 本文为非平稳、具有相关记忆的高斯驱动建立路径积分结构。它与“给定粗糙驱动后解方程”的结果互补：先提升噪声，再单独检查方程系数的条件。

**值得进一步研究的问题：** **本期提出：** 降低 Hurst 函数自身的时间正则性后，光滑余项是否仍可用有限变差平移处理？若不能，提升所需的额外迭代积分应怎样构造？

## 本期观察

本期三篇都提示：改变路径结构后，要先找到控制性质的对象。boosted LERW 看随机补域的谱；Volterra 模型看换测度后的反馈与爆炸；mBm 看最低 Hurst 参数及高频协方差估计。它们分别控制的是路径律、期望保持和积分结构，不能互相替代。
