### Critical Branching Systems with General Lifetimes: Hunt Motions and Applications to Semilinear Equations

{{< paper-meta
  authors="Ekaterina T. Kolkovska、José Alfredo López-Mimbela、José Hermenegildo Ramírez-González"
  source="arXiv 预印本"
  date="2026-11-07 · v1"
  arxiv="2611.10339"
  fulltext="https://arxiv.org/html/2611.10339v1"
  fulltextLabel="全文 v1"
  directions="分支过程"
>}}

**研究问题与背景。** 临界意味着粒子的平均后代数为一，但这还不足以预测一个固定区域长期是否有粒子。作者将空间运动的扩散速度、粒子寿命和后代律放进同一个判据。

**核心模型。** 初始粒子是以 Lebesgue 测度为强度的 Poisson 场。粒子在欧氏空间或非负正交象限中按保守 Hunt 过程运动，在独立寿命结束时繁殖，后代生成函数为 {{< math >}}f(s)=s+c(1-s)^{1+\beta}{{< /math >}}，其中 {{< math >}}0<\beta\le1{{< /math >}}、{{< math >}}0<c<(1+\beta)^{-1}{{< /math >}}。对运动的假设包括 Lebesgue 不变性、进入任意紧集的概率一致为 {{< math >}}O(t^{-q}){{< /math >}}，以及体积至多为 {{< math >}}O(t^q){{< /math >}} 的区域之外的祖先对该紧集的贡献可一致控制。

**主要结果。** 定理 2.1 对具有有限均值的 spread-out 寿命律证明，当 {{< math >}}q\beta>1{{< /math >}} 时，粒子测度依分布趋于一个非平凡、强度仍为 Lebesgue 测度的随机 Radon 测度。当 {{< math >}}q\beta\le 1{{< /math >}} 时，趋于零测度。定理 2.2 对非格点、尾部渐近为 {{< math >}}c_1t^{-\gamma}{{< /math >}}（{{< math >}}0<\gamma\le1{{< /math >}}）的寿命律，将阈值改为 {{< math >}}q\beta=\gamma{{< /math >}}。阈值上方趋于 Poisson 随机测度，下方趋于零，等号时证明存在非平凡子序列极限。

**方法与证明思路。** 先按第一代寿命分解粒子测度的 Laplace 泛函，得到更新方程，再用更新测度的渐近和空间半群估计控制非线性项。局部化条件允许将固定区域内的质量与有控制的祖先区域联系起来。

**与研究主线的关联。** 两条定理把局部灭绝与空间扩散、后代波动及繁殖时钟联系起来，适合比较具有不同寿命机制的临界年龄依赖分支模型。

**值得进一步研究的问题。** 本期提出，在临界等号情形，哪些附加条件能把非平凡子序列极限提升为全序列收敛？

### Exponential Mixing for the Randomized Two-vortex Model

{{< paper-meta
  authors="Yankai Shi"
  source="arXiv 预印本"
  date="2026-11-09 · v1"
  arxiv="2611.12535"
  fulltext="https://arxiv.org/html/2611.12535v1"
  fulltextLabel="全文 v1"
  directions="随机流"
>}}

**研究问题与背景。** 确定性点涡旋可能同时产生混沌和局部规则区域。本文问，在双涡旋位置上加入噪声后，固定噪声样本下的拉格朗日流能否实现全局混合。

**核心模型。** 两个涡旋在二维环面上经固定尺度的高斯正则化 Biot–Savart 核相互作用，并分别受独立布朗运动驱动。两涡旋位置生成随机、光滑且无散的速度场。被动粒子沿该场运动，同一噪声样本下共享一个保体积流。

**主要结果。** 定理 1.1 证明，对任意 {{< math >}}s,q>0{{< /math >}}，存在确定的正指数 {{< math >}}\gamma_{s,q}{{< /math >}} 及有有限 {{< math >}}q{{< /math >}} 阶矩的随机前因子 {{< math >}}D{{< /math >}}。对零均值的 {{< math >}}H^s{{< /math >}} 观测量，几乎必然有

{{< math display="true" >}}\left|\int_{\mathbb{T}^2} f(x)g(\phi_t(x))\,dx\right|\le D\|f\|_{H^s}\|g\|_{H^s}e^{-\gamma_{s,q}t}.{{< /math >}}

**方法与证明思路。** 两个被动粒子在共同随机场中演化。作者用一致收缩估计构造控制近对角线区域的 Lyapunov 函数，再用可控性证明固定时间骨架的 minorization，借助 Harris 定理得到二点过程的几何遍历性，进而导出样本路径上的相关衰减。

**与研究主线的关联。** 这是从二点随机动力学推出流混合的例子。二点过程需要控制两条共享噪声的轨道，因而比单点位置的遍历性更贴近输运问题。

**值得进一步研究的问题。** 作者指出，混合速率对核正则化尺度及涡旋数目的定量依赖仍待研究。定理中的常数可以依赖正则化尺度。

### Phase Transitions for Random Least Common Multiples with Memory

{{< paper-meta
  authors="Shaochen Wang、Guangyu Yang、Wang Zhou"
  source="arXiv 预印本"
  date="2026-11-08 · v1"
  arxiv="2611.11301"
  fulltext="https://arxiv.org/html/2611.11301v1"
  fulltextLabel="全文 v1"
  directions="非马尔可夫过程、自相互作用随机游走"
>}}

**研究问题与背景。** 随机选取一批整数，再计算它们的最小公倍数。如果单个整数的保留概率相同，复制历史决定造成的相关性是否仍会改变这个算术量的极限？

**核心模型。** 每一步以概率 {{< math >}}a{{< /math >}} 均匀抽取一个历史位置并复制它的保留决定，否则独立抽取参数为 {{< math >}}\theta{{< /math >}} 的 Bernoulli 变量。保留数是步长取零或一的正步长强化随机游走。令 {{< math >}}T_n{{< /math >}} 为所选整数最小公倍数的对数。

**主要结果。** 定理 2.1 对固定保留率 {{< math >}}\theta\in(0,1){{< /math >}} 证明，{{< math >}}T_n/n{{< /math >}} 依概率趋于 {{< math >}}\theta\log(1/\theta)/(1-\theta){{< /math >}}。当 {{< math >}}a<1/2{{< /math >}} 时，中心化涨落除以 {{< math >}}\sqrt{n\log n}{{< /math >}} 得到高斯极限。等号时尺度相同，但方差多出记忆项。当 {{< math >}}1/2<a<1{{< /math >}} 时，尺度改为 {{< math >}}n^a{{< /math >}}，极限为中心化保留数的非退化鞅极限乘一个正系数。

**方法与证明思路。** von Mangoldt 恒等式将对数最小公倍数写成按素数幂加权的整除覆盖指标。作者把固定密度下的主要涨落拆成创新鞅和记忆项，再把后者投影到保留数的涨落。复制关系形成的谱系森林则用于处理稀疏保留时的簇极限。

**与研究主线的关联。** 强化游走的相变经由保留数传到一个非线性的算术观测量。临界点的附加方差给出了记忆效应在算术尺度上首次可见的具体形式。

**值得进一步研究的问题。** 本期提出，如果历史位置按年龄加权抽样，什么条件能保证保留数仍捕捉最小公倍数涨落中的主要记忆效应？
