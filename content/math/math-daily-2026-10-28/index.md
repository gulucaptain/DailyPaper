### Optimal Rates in Local and Central Limit Theorems for the Elephant Random Walk

{{< paper-meta
  authors="Hideki Murahara、Go Tokumitsu"
  source="arXiv 预印本"
  date="2026-10-26 · v1"
  arxiv="2610.35019"
  fulltext="https://arxiv.org/html/2610.35019v1"
  fulltextLabel="全文 v1"
  directions="自相互作用随机游走、非马尔可夫过程"
>}}

**研究问题与背景：** 对象随机游走（elephant random walk, ERW），中心极限定理已知，但“趋向高斯”并不能说明误差到底有多大。本文把局部概率与分布函数、精确标准化与渐近标准化、对称与偏置初始分布分开，得到相应的最优速率。

**核心模型与数学设定：** 初始增量满足 {{< math >}}\mathbb P(X_1=1)=q{{< /math >}}。随后均匀回忆一个过去增量，以概率 {{< math >}}p{{< /math >}} 重复它，以概率 {{< math >}}1-p{{< /math >}} 反向，位置为 {{< math >}}S_n=\sum_{j=1}^nX_j{{< /math >}}。本文研究 {{< math >}}0\le p\le3/4{{< /math >}}，{{< math >}}q\in[0,1]{{< /math >}}。记精确均值、方差为 {{< math >}}\mu_n{{< /math >}}、{{< math >}}v_n^2{{< /math >}}，并定义

{{< math display="true" >}}
Z_n=\frac{S_n-\mu_n}{v_n}.
{{< /math >}}

扩散区间 {{< math >}}p<3/4{{< /math >}} 有 {{< math >}}v_n^2\sim n/(3-4p){{< /math >}}；临界点为 {{< math >}}v_n^2\sim n\log n{{< /math >}}。这些方差渐近与中心极限定理是已有基础，本文推进的是更细的展开与最优误差。

**主要定理或理论结果：** **定理1.1、1.2**建立含三、四阶累积量修正的统一 Edgeworth 展开。局部概率只取 {{< math >}}s\equiv n\pmod2{{< /math >}}，并使用 {{< math >}}v_n\mathbb P(S_n=s)/2{{< /math >}} 与高斯密度比较；分母2来自格点跨度，不能省略。

令 {{< math >}}D_n{{< /math >}} 表示 {{< math >}}Z_n{{< /math >}} 与标准正态分布的 Kolmogorov 距离。**定理1.5**给出固定参数下的双边阶数：对称初始分布 {{< math >}}q=1/2{{< /math >}} 时，{{< math >}}p\le11/16{{< /math >}} 的速率为 {{< math >}}n^{-1/2}{{< /math >}}；{{< math >}}11/16<p<3/4{{< /math >}} 时变为 {{< math >}}n^{8p-6}{{< /math >}}。固定偏置 {{< math >}}q\ne1/2{{< /math >}} 时，转折点改为 {{< math >}}2/3{{< /math >}}，其后至临界前的速率为 {{< math >}}n^{6p-9/2}{{< /math >}}。

临界点尤其能看出标准化的区别。下表“渐近标准化”指 {{< math >}}S_n/\sqrt{n\log n}{{< /math >}}：

| 标准化 | 对称 | 固定偏置 |
|---|---|---|
| 精确标准化 | {{< math >}}(\log n)^{-2}{{< /math >}} | {{< math >}}(\log n)^{-3/2}{{< /math >}} |
| 渐近标准化 | {{< math >}}(\log n)^{-1}{{< /math >}} | {{< math >}}(\log n)^{-1/2}{{< /math >}} |

第二行来自**推论1.6**。以上都是上下界匹配的阶数，常数允许依赖固定 {{< math >}}p,q{{< /math >}}；不是说在初始偏置趋零时仍有统一的正下界。**定理1.3**的局部概率误差还会出现其他阈值，不能直接套用分布函数的这张表。

**方法与证明思路：** 使用 elephant polynomials 精确分析特征函数和累积量，再借助随机递归树表示控制整体 Fourier 区间。Edgeworth 修正项识别主要误差来源；格点效应、偏置和方差修正的竞争解释不同阈值。

**与研究主线的关联：** 增量生成规则显式回忆历史，直接属于自相互作用游走。需要补充的是：本模型的位置 {{< math >}}S_n{{< /math >}} 本身可以写成时间非齐次 Markov 链，因此不能把“有回忆的构造”误写成任何状态表示下都非马尔可夫。

**值得进一步研究的问题：** **本期提出：** 若初始偏置随 {{< math >}}n{{< /math >}} 趋零，两种速率分类之间会出现什么过渡尺度？这需要同时跟踪偏置修正项和格点误差，固定参数的定理尚未直接回答。

### Exceptional times of compact support for α-stable superprocesses

{{< paper-meta
  authors="Jieliang Hong、Leonid Mytnik"
  source="arXiv 预印本"
  date="2026-10-26 · v1"
  arxiv="2610.34757"
  fulltext="https://arxiv.org/html/2610.34757v1"
  fulltextLabel="全文 v1"
  directions="分支过程"
>}}

**研究问题与背景：** 带跳跃空间运动的超过程可以瞬时传播：对每个固定正时间，条件于尚未灭绝，其支集几乎必然是整个空间。但固定时刻的结论不排除随机路径中存在异常时刻。本文证明，紧且非空支集的异常时刻不仅存在，而且在灭绝前的每个非平凡时间区间内都具有满 Hausdorff 维数。

**核心模型与数学设定：** 空间为 {{< math >}}\mathbb R^d{{< /math >}}，{{< math >}}d\ge1{{< /math >}}，空间运动是对称 {{< math >}}\alpha{{< /math >}}-stable 过程，{{< math >}}0<\alpha<2{{< /math >}}。从任意非零有限测度 {{< math >}}X_0{{< /math >}} 出发，使用 Dawson–Watanabe 的二次分支机制。这里 {{< math >}}\alpha{{< /math >}} 描述**空间运动**，不是分支机制的稳定指数。总质量是 Feller 分支扩散，记其灭绝时刻为 {{< math >}}\zeta{{< /math >}}。

设 {{< math >}}S(X_t){{< /math >}} 为测度支集，并令

{{< math display="true" >}}
H=\{t>0:S(X_t)\text{ 紧且非空}\}.
{{< /math >}}

**主要定理或理论结果：** **定理1.1**证明，几乎必然对所有 {{< math >}}0\le s<t\le\zeta{{< /math >}}，

{{< math display="true" >}}
\dim_H\bigl(H\cap(s,t)\bigr)=1.
{{< /math >}}

此结论把此前 {{< math >}}0<\alpha<2/3{{< /math >}} 的范围扩展到完整 {{< math >}}0<\alpha<2{{< /math >}}，初始测度不必紧支撑。与此同时，支集在灭绝前 Lebesgue 几乎处处的时间仍是全空间。因此**维数1并不意味着这些异常时刻占有正的时间长度**。

**定理1.2**还描述灭绝点 {{< math >}}F{{< /math >}} 附近的支集坍缩：给定任意 {{< math >}}r>0{{< /math >}}，在每个 {{< math >}}(t,\zeta){{< /math >}} 中，非零支集全部落在以 {{< math >}}F{{< /math >}} 为中心、半边长为 {{< math >}}r{{< /math >}} 的闭立方体内的时刻集合，Hausdorff 维数也是1。这是异常时间集合的结论，不能改写为所有接近灭绝的时刻都具有小支集。

**方法与证明思路：** 将过程分为区域内被杀死的部分及离开区域质量的后代。后者总质量可以表示为从零出发、带移民的 Feller 分支扩散；当这部分质量恰为零时，原过程支集便留在有界区域内。

关键新工具是**定理1.4**：对确定性、连续非减的累计移民函数 {{< math >}}a{{< /math >}}，只要总移民量足够小，零点集在给定开区间内就以任意高概率具有任意接近1的维数，且阈值对移民轮廓一致。它允许奇异连续移民，不要求移民密度存在。以累计移民的一阶控制代替瞬时移民率的高阶估计，是去掉旧参数限制的关键。

**与研究主线的关联：** 这项工作把测度值分支系统的空间支集几何，转化为带移民分支扩散的零点几何。它说明固定时间概率与整条样本路径的异常行为可以差别很大。

**值得进一步研究的问题：** **本期提出：** 更换二次分支机制后，小总移民量是否仍足以控制零点集维数？需要重新检查零点结构，不能仅根据空间稳定运动就照搬本结论。

### Persistent occupation and critical marked sums on branching random walks

{{< paper-meta
  authors="Abderrahman Skiredj、Ismail Berrada"
  source="arXiv 预印本"
  date="2026-10-24 · v1"
  arxiv="2610.33897"
  fulltext="https://arxiv.org/html/2610.33897v1"
  fulltextLabel="全文 v1"
  directions="分支过程"
>}}

**研究问题与背景：** 分支树里可能有许多路径分别频繁访问某个空间层，但这不意味着存在**同一条无限路径**，在所有足够高的层上都频繁访问。本文的持久占用结果直接处理这个量词问题；以下重点介绍该部分，标记路径和的其他结果不在本期展开。

**核心模型与数学设定：** 每个顶点独立复制同分布的后代位移列表 {{< math >}}(Y_i)_{1\le i\le N}{{< /math >}}，同胞位移之间可以依赖。先假设位移为整数且 {{< math >}}Y_i\le1{{< /math >}}。存在指数倾斜参数 {{< math >}}t>0{{< /math >}}，满足原文式(3)–(4)：

{{< math display="true" >}}
\begin{gathered}
\mathbb E\sum_i e^{-tY_i}=1,\qquad
\mathbb E\sum_iY_i e^{-tY_i}=0,\\
0<\sigma^2=\mathbb E\sum_iY_i^2e^{-tY_i}<\infty,\\
\Psi=\mathbb E\sum_{i\ne j}e^{-tY_i-tY_j}<\infty.
\end{gathered}
{{< /math >}}

这里 {{< math >}}t{{< /math >}} 不是观察时间，{{< math >}}\sigma^2{{< /math >}} 是倾斜后单步分布的方差。对无限谱系射线 {{< math >}}\xi{{< /math >}}，记 {{< math >}}N_\xi^k{{< /math >}} 为沿这条射线访问空间层 {{< math >}}k{{< /math >}} 的总次数。

**主要定理或理论结果：** **定理1**在存活事件上构造一条无限射线，使 {{< math >}}\liminf_{k\to\infty}N_\xi^k/k^2{{< /math >}} 严格为正。要点是先固定一条射线，再让空间层趋于无穷；不是每一层重新选一条路径。

若进一步限制 {{< math >}}Y_i\in\{-1,0,1\}{{< /math >}}，**定理5**给出同一射线可达到的显式下界

{{< math display="true" >}}
\liminf_{k\to\infty}\frac{N_\xi^k}{k^2}
\ge\frac{4t}{\sigma^2j_{1,1}^2},
{{< /math >}}

其中 {{< math >}}j_{1,1}{{< /math >}} 是 Bessel 函数 {{< math >}}J_1{{< /math >}} 的首个正零点。相应变分轮廓的最佳系数为 {{< math >}}4/j_{1,1}^2\approx0.27244{{< /math >}}。它是**该构造下界**的优化常数，尚不是所有无限射线之间的全局最优常数。原文结合**定理3**给出的上界为 {{< math >}}t/\sigma^2{{< /math >}}；两者之间仍有缺口。

**方法与证明思路：** 指数倾斜的 many-to-one 恒等式把树上的加权计数转为中心化普通随机游走。仅有逐层的一、二阶矩还不够，作者通过嵌套占用区块及存活的嵌入树，把各层的好行为拼接到同一射线。最近邻含零位移情形再使用重叠前向轮廓和 Bessel 型变分问题提高下界。

**与研究主线的关联：** 这是分支随机游走中，单条无限谱系的局部时与空间占用问题。有限同胞加权矩和“向上至多一步”的位移约束都参与构造，不能把结果直接推广为任意分支游走的普适常数。

**值得进一步研究的问题：** **作者明确留下的问题：** 全局最优持久局部时常数能否等于当前构造下界？是否存在一条射线真正达到全局最优值？原文明确保留了这两个问题；本期建议先研究上下界缺口与位移分布的关系。

## 本期观察

三篇都需要区分看起来相近、实际不同的对象：高斯逼近要分标准化与误差类型；异常时间要分 Hausdorff 维数与 Lebesgue 测度；分支路径要分“每层存在一条”与“存在一条适用于每层”。把比较对象和量词先写清楚，往往比先记住临界常数更有帮助。
