### Localisation of the monkey walk with an "impurity" at the origin

{{< paper-meta
  authors="Wilfred Armfield、Cécile Mailler"
  source="arXiv 预印本"
  date="2026-10-15 · v1"
  note="次日公告"
  directions="自相互作用随机游走、非马尔可夫过程"
  arxiv="2610.21864"
  fulltext="https://arxiv.org/html/2610.21864v1"
  fulltextLabel="全文 v1"
>}}

**一句话总结：** 原点处较低的历史重定位概率，可以使长期记忆游走在足够强的异质参数区间中局域化。

**研究问题与背景：** 均匀参数monkey walk会以对数尺度缓慢扩散。加入单点杂质后，物理研究预测了局域化区域；本文给出其中一部分参数区间的严格证明。

**核心模型与数学设定：** 在整数格上，每步或者作简单对称最近邻跳跃，或者均匀选择一个过去时刻并返回当时的位置。原点的重定位概率为 {{< math >}}\xi_0{{< /math >}}，其余位置为 {{< math >}}\xi{{< /math >}}，满足 {{< math >}}0<\xi_0<\xi<1{{< /math >}}。归一化占据测度为

{{< math display="true" >}}
\widetilde M_n=\frac{1}{n+1}\sum_{j=0}^{n}\delta_{W_j}.
{{< /math >}}

**主要定理或理论结果：** 定理1.1证明：任意维数 {{< math >}}d\geq1{{< /math >}} 和任意固定 {{< math >}}\xi_0\in(0,1){{< /math >}}，存在依赖它们的 {{< math >}}\Xi<1{{< /math >}}，使得 {{< math >}}\xi\in(\Xi,1){{< /math >}} 时，占据测度在弱收敛拓扑下几乎必然收敛到概率测度。正文第1.2节进一步说明位置分布无需空间归一化即收敛。本文没有证明整个物理预测区域都发生局域化，也没有给出完整相变曲线。

**方法与证明思路：** 将重定位时刻的占据过程写成测度值Pólya过程，利用相关被杀死过程的准平稳行为研究极限；难点在于既有测度值urn收敛定理的条件不能直接套用，需要补充论证。

**与研究主线的关联：** 记忆通过整个历史占据分布反馈到转移规则，单点杂质改变长期标度，是非马尔可夫强化机制与局域化相互作用的直接例子。

**值得进一步研究的问题：** 作者在第1.2节明确留下弱杂质区间的扩散性质与速度问题；本期建议优先关注如何降低充分局域化阈值，并与物理预测条件比较，而不要把该预测条件当成本文定理。

### A sharp survival threshold for branching Brownian motion in a self-generated resource environment

{{< paper-meta
  authors="Maciej Głuchowski、Georg Menz"
  source="arXiv 预印本"
  date="2026-10-15 · v1"
  directions="分支过程"
  arxiv="2610.21476"
  fulltext="https://arxiv.org/html/2610.21476v1"
  fulltextLabel="全文 v1"
>}}

**一句话总结：** 在有限程、局部正相互作用核下，每个死亡粒子可支持的理论出生数量是否超过1，决定正概率生存是否可能。

**研究问题与背景：** 标准分支布朗运动中个体独立繁殖；这里出生率依赖共享且会被消耗的资源，死亡又补充资源，独立分支结构被反馈机制打破。

**核心模型与数学设定：** 在任意 {{< math >}}d\geq1{{< /math >}} 维空间中，粒子测度和资源测度均从确定的有限初态开始。出生率为附近资源乘出生系数，资源按附近粒子数消耗，每次死亡返还资源质量。相互作用核非负、有界、对称、Borel可测且非零。关键参数为

{{< math display="true" >}}
\theta=\frac{\beta m}{c},
{{< /math >}}

其中 {{< math >}}\beta,c,m>0{{< /math >}} 分别表示出生系数、消耗系数和每次死亡返还的资源量；扩散系数与死亡率也取正。

**主要定理或理论结果：** 定理1(i)证明 {{< math >}}\theta\leq1{{< /math >}} 时，从任意有限初态几乎必然在有限时间灭绝。定理1(ii)在 {{< math >}}\theta>1{{< /math >}}、核具有有限支撑且在原点某邻域有严格正下界的条件下，证明正概率生存当且仅当初态至少有两个粒子，或恰有一个粒子且有正资源质量。阈值与维数等参数无关的表述限于定理覆盖的模型和核条件，不能推广为任意长程核的结论。

**方法与证明思路：** 灭绝侧以总资源加加权粒子数构造非负超鞅；收敛排除无限多次出生。生存侧分开控制“资源被消耗便会产生出生”和“稠密群体能高效回收死亡资源”，再用群体倍增与重启论证维持增长。

**与研究主线的关联：** 这是共享资源诱导相互作用的分支粒子系统，核心问题正是灭绝、生存与临界行为。联合状态具有马尔可夫性，不宜仅因存在环境反馈就把它称为非马尔可夫定理。

**值得进一步研究的问题：** 本期提出：长程相互作用或随机死亡返还量下，资源利用效率还能否导出同样尖锐的阈值？本文并未解决这些推广。

### Persistence in probability for stochastic delay equations with multiplicative noise

{{< paper-meta
  authors="Mark van den Bosch、John Ioannis Stavroulakis"
  source="arXiv math.DS"
  date="2026-10-15 · v1"
  note="交叉收录至 math.PR"
  directions="非马尔可夫过程"
  arxiv="2610.21599"
  fulltext="https://arxiv.org/html/2610.21599v1"
  fulltextLabel="全文 v1"
>}}

**一句话总结：** 一个不显含时滞长度的充分条件，保证正解在整个时间轴上一致地依概率远离零。

**研究问题与背景：** 延迟反馈使当前标量状态不能独立决定未来。研究目标是严格刻画小噪声下非线性种群模型是否会在概率意义上保持正数量，而非只讨论解的逐时正性。

**核心模型与数学设定：**

{{< math display="true" >}}
\mathrm dX(t)=[-\gamma X(t)+rf(X(t-\tau))]\,\mathrm dt+\sigma X(t)\,\mathrm dW(t).
{{< /math >}}

参数 {{< math >}}\gamma,r,\tau>0{{< /math >}}、{{< math >}}\sigma\geq0{{< /math >}}；函数全局Lipschitz，或者局部Lipschitz且全局有界，并满足 {{< math >}}f(0)=0{{< /math >}}、正半轴非负，以及 {{< math >}}\kappa=\liminf_{x\downarrow0}f(x)/x>0{{< /math >}}。初始历史连续、非负，且时刻零的值几乎必然严格正。

**主要定理或理论结果：** 定理1.1证明，若 {{< math >}}r\kappa>\gamma+\sigma^2/2{{< /math >}}，则解全局存在、保持正性，并满足

{{< math display="true" >}}
\lim_{\varepsilon\downarrow0}\sup_{t\geq0}\mathbb P\{X(t)\leq\varepsilon\}=0.
{{< /math >}}

该不等式是充分条件，不能写成一般模型下已证明的必要充分阈值。获得非平凡不变测度还需配合上方紧性等条件；原文在有界非线性情形继续讨论这些条件。

**方法与证明思路：** 用随机积分因子改写时滞方程，与线性比较方程联系，通过负条件矩的收缩估计控制接近零的概率。正文也从线性比较方程的首Lyapunov指数组织更一般的持久性分析。

**与研究主线的关联：** 历史段是自然状态空间，适合研究带记忆随机动力学中的稳定性。判据不显含时滞长度，不等于轨道分布或收敛速度不受时滞影响。

**值得进一步研究的问题：** 本期提出：对特定反馈函数，显式充分条件与真实持久性边界之间的差距能否量化？数值显示的边界应与严格定理分开处理。

### A Generalized Elephant Random Walk with Time-Dependent Memory

{{< paper-meta
  authors="Xiequan Fan、Yongcheng Qi"
  source="arXiv 预印本"
  date="2026-10-12 · v1"
  directions="自相互作用随机游走、非马尔可夫过程"
  arxiv="2610.16065"
  fulltext="https://arxiv.org/html/2610.16065v1"
  fulltextLabel="全文 v1"
>}}

**一句话总结：** 时变象随机游走的高斯与鞅极限行为，可用累积方差序列是否发散统一组织。

**研究问题与背景：** 经典象随机游走以常数记忆参数区分不同扩散区域。本文改变重复或反转的概率序列，并不改变可被采样的完整记忆集合；两种“时变记忆”不能混为一谈。

**核心模型与数学设定：** 初始增量取正负1，取正概率为 {{< math >}}q\in[0,1]{{< /math >}}；第n步从过去n个增量中均匀抽样，以 {{< math >}}p_n\in[0,1]{{< /math >}} 的概率重复，否则反向。记位置为 {{< math >}}S_n{{< /math >}}，并按原文定义

{{< math display="true" >}}
a_n=2p_n-1,\quad A_1=A_2=\tfrac12,\quad A_n=\tfrac12\prod_{k=2}^{n-1}(1+a_k/k)^{-1},\quad V_n=\sum_{k=2}^{n}A_k^2.
{{< /math >}}

**主要定理或理论结果：** 定理2.1–2.3在 {{< math >}}V_n\to\infty{{< /math >}} 下证明强大数律、中心极限定理及重对数律；其中

{{< math display="true" >}}
\frac{A_nS_n}{\sqrt{V_n}}\Rightarrow N(0,1).
{{< /math >}}

定理2.4在方差序列有有限极限时证明 {{< math >}}A_nS_n{{< /math >}} 几乎必然且在四阶矩意义下收敛。极限是否非退化以及是否非高斯另有条件，不能把任意参数序列都写成“必然出现非高斯极限”。

**方法与证明思路：** 把历史依赖增量组织成适当归一化的鞅，分别控制其条件方差和增量，再应用鞅极限定理。显式参数序列的例子展示了常数参数三分法之外更丰富的归一化速度。

**与研究主线的关联：** 这是完整记忆随机游走的直接推广，为非平稳强化机制提供了可计算的方差判据。

**值得进一步研究的问题：** 本期提出：振荡或分段变化的参数序列，在何种条件下具有稳定的路径空间极限？本文的单时刻CLT不能自动替代函数型极限定理。

### The forward-loop-erased ants walk

{{< paper-meta
  authors="Wilfred Armfield、Cécile Mailler"
  source="arXiv 预印本"
  date="2026-10-13 · v1"
  directions="自相互作用随机游走"
  arxiv="2610.18453"
  fulltext="https://arxiv.org/html/2610.18453v1"
  fulltextLabel="全文 v1"
>}}

**一句话总结：** 在巢穴到食物的图距离为2时，前向擦环强化机制可在不额外限制图形状的情况下找到最短路。

**研究问题与背景：** 蚂蚁依次在有限图上寻找食物，已有蚂蚁的轨迹改变边权，从而影响后续路径。问题是局部强化能否排除非最短路线。

**核心模型与数学设定：** 蚂蚁从巢穴出发，按边权随机行走，首次到达食物即停止。在去程中一形成环就将其擦除，返程沿擦环后路径行走，并将经过边的权重加1。主定理考虑简单有限图，巢穴与食物不直接相邻且至少有一条长为2的路径；归一化权重采用原文式(1.1)的分母。

**主要定理或理论结果：** 定理1.1证明，在上述距离2条件下，最短路上成对边的归一化权重之差几乎必然趋零，所有非最短路边的归一化权重几乎必然趋零，从而得到论文定义下的“找到最短路”。距离1的情形由已有工作覆盖。本文没有证明任意距离的最短路发现，也没有证明整个归一化边权向量必然收敛；后者在第1.2节仍被列为开放问题。

**方法与证明思路：** 使用随机逼近处理权重演化，以电网络有效电导估计转移行为，并利用加权均匀生成树结构。证明还需排除随机逼近落在不稳定零点的可能性。

**与研究主线的关联：** 强化发生在跨越多只蚂蚁的历史中，边权携带记忆。这里的最短路选择与单个游走的长期局域化不同，但共享历史反馈的数学结构。

**值得进一步研究的问题：** 作者明确指出，距离至少3时现有方法不能直接推广；本期建议把这个障碍与完整边权向量收敛问题分别研究。

### Stochastic Flows with Strong Shear - Part I: Strong Completeness and Set Attractors

{{< paper-meta
  authors="Dennis Chemnitz、Maximilian Engel、Michael Scheutzow"
  source="arXiv 预印本"
  date="2026-10-05 · v1"
  note="窗口内未收录的近期补遗"
  directions="随机流"
  arxiv="2610.06321"
  fulltext="https://arxiv.org/html/2610.06321v1"
  fulltextLabel="全文 v1"
>}}

**一句话总结：** 径向耗散并不保证全局随机流：足够强的角向剪切与同一噪声耦合，会产生依赖噪声实现的异常爆炸初值。

**研究问题与背景：** 每个固定初值的解几乎必然不爆炸，仍可能不存在一个共同的满概率事件使所有初值的解同时全局存在。本文研究这两种量词顺序不同的性质，以及紧集是否被随机吸引。

**核心模型与数学设定：** 标准化后的二维方程为

{{< math display="true" >}}
\mathrm dX=-X\,\mathrm dt+\rho(|X|)JX\,\mathrm dt+\mathrm dW,\qquad J=\begin{pmatrix}0&1\\-1&0\end{pmatrix}.
{{< /math >}}

其中 {{< math >}}\rho\in C^2([0,\infty)){{< /math >}} 且 {{< math >}}\rho'(0)=0{{< /math >}}，原模型的正耗散系数和正噪声强度可通过时空缩放标准化。单点半径的分布与平面OU过程相同，但多初值在同一噪声下的相互耦合仍受剪切影响。

**主要定理或理论结果：** 定理B(a)给出强完备性的积分充分条件：

{{< math display="true" >}}
\int_0^\infty\left(1\vee\sup_{0\leq s\leq r}|\rho'(s)|\right)^{-1/3}\,\mathrm dr=\infty.
{{< /math >}}

定理B(b)在大半径处导数受足够小常数倍三次增长控制时，给出弱集合吸引子。定理C的反向结果**还要求**大半径处 {{< math >}}|\rho'|{{< /math >}} 单调递增，以及 {{< math >}}\limsup_{r\to\infty}|\rho''(r)|/|\rho'(r)|<\infty{{< /math >}}。在这些条件及足够大的三次增长下，不存在弱集合吸引子；再加入 {{< math >}}\int_{r_*}^{\infty}|\rho'(r)|^{-1/3}\,\mathrm dr<\infty{{< /math >}}，则不强完备，几乎每个噪声实现都有异常初值在有限时间逃向无穷。不能省略这些正则与单调条件，也不能把异常初值的存在写成每个固定初值都会爆炸。

**方法与证明思路：** 正向估计追踪离散球族的增长以控制初值集合；反向构造反复追踪两点，利用强剪切调整噪声的径向作用，并在积分可积条件下将逃逸压缩到有限时间。

**与研究主线的关联：** 这是随机流存在性与集合稳定性的直接结果，说明单点不变分布或单轨道非爆炸不足以推断整个流的行为。

**值得进一步研究的问题：** 本期提出：放松导数的最终单调性，或允许剪切符号和强度剧烈振荡后，积分判据是否仍能给出接近必要充分的分类？本文的定理不自动覆盖这些情形。

## 本期观察

本期的共同主题是历史或共同环境如何改变长期行为：monkey walk与蚂蚁游走通过历史占据或边权强化；时滞方程与象随机游走分别通过连续历史段和离散增量记忆进入极限定理。分支系统的资源反馈则改变个体独立性，随机流论文强调同一噪声下初值集合的行为。它们使用的状态空间与概率结论不同，不能统一概括为一种相变。

尤其需要保留结论边界：局域化的充分区间不等于完整相图；依概率持久性不等于逐路径统一正下界；最短路发现不等于全部边权收敛；逐初值非爆炸不等于强完备。

## 阅读建议

- **monkey walk局域化**：适合从完整记忆、准平稳分布和测度值Pólya过程的联系切入。
- **资源反馈分支布朗运动**：优先阅读定理1的初态条件及临界灭绝证明，再看稠密群体倍增论证。
- **强剪切随机流**：先对照定理B与C的假设，理解强完备性中的共同满概率事件，再读反向构造。
