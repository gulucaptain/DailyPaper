### The bias interval of the elephant random walk

{{< paper-meta
  authors="Arjun Pemmasani"
  source="arXiv 预印本"
  date="2026-11-10 · v1"
  arxiv="2611.14576"
  fulltext="https://arxiv.org/html/2611.14576v1"
  fulltextLabel="全文 v1"
  directions="自相互作用随机游走、非马尔可夫过程"
>}}

**研究问题与背景。** 超扩散象随机游走的极限密度可以有两个峰。本文研究的是哪些初始偏置会产生双峰，以及这种现象从多大的记忆强度开始出现。

**核心模型。** 每一步均匀抽取一个历史步，以概率 {{< math >}}p{{< /math >}} 复制方向，否则反转。记忆参数为 {{< math >}}a=2p-1{{< /math >}}，初始向右概率为 {{< math >}}q{{< /math >}}。在 {{< math >}}1/2<a<1{{< /math >}} 下，位置除以 {{< math >}}n^a{{< /math >}} 几乎必然收敛。若向右起步时的极限密度为 {{< math >}}h_a{{< /math >}}，则一般起步的密度为

{{< math display="true" >}}g_{a,q}(u)=qh_a(u)+(1-q)h_a(-u).{{< /math >}}

**主要结果。** 定理 1 证明，对每个超扩散参数，都存在 {{< math >}}b_a\in(0,1/2]{{< /math >}}，极限密度恰在 {{< math >}}b_a<q<1-b_a{{< /math >}} 时有两个局部极大值。区间外以及两个端点处都只有一个局部极大值。定理 2 证明存在唯一阈值 {{< math >}}a_*\in(2/3,0.69){{< /math >}}，使该双峰区间恰在 {{< math >}}a>a_*{{< /math >}} 时非空。约 {{< math >}}0.6688{{< /math >}} 是数值近似，唯一性由解析论证给出。

**方法与证明思路。** 作者从有限步分布的一阶、二阶离散差分入手，控制符号变化，包括支撑边界产生的变化，再将这些结构传递到极限密度。公平起步密度在原点的曲率有正权积分表示，用于确定阈值的唯一性。

**与研究主线的关联。** 结果在超扩散区间内部进一步区分了极限分布的形状。记忆强度与初始偏置共同决定单双峰，而初始偏置对应一个关于二分之一对称的开区间。

**值得进一步研究的问题。** 作者在文末提出，当记忆趋于一时，能否得到偏置边界更精确的渐近。本文命题 16 已给出 {{< math >}}b_a=O((1-a)^2){{< /math >}} 的上界。

### Strong Well-Posedness and Path-by-Path Uniqueness for Fractional SDEs with Integrable Drifts

{{< paper-meta
  authors="Oleg Butkovsky、Khoa Lê、Toyomu Matsuda"
  source="arXiv 预印本"
  date="2026-11-12 · v1"
  arxiv="2611.16344"
  fulltext="https://arxiv.org/html/2611.16344v1"
  fulltextLabel="全文 v1"
  directions="非马尔可夫过程、随机流"
>}}

**研究问题与背景。** 分数布朗运动在 Hurst 参数小于二分之一时具有粗糙、相关的增量。本文研究这种噪声能否使可积但缺少经典光滑性的漂移方程适定，并构造所有初值共享的解族。

**核心模型。** 在 {{< math >}}\mathbb R^d{{< /math >}} 中考虑加性噪声方程

{{< math display="true" >}}X_t=x+\int_0^t b(r,X_r)\,dr+B_t^H,\qquad 0<H<\tfrac12.{{< /math >}}

漂移属于 {{< math >}}L^q_tL^p_x{{< /math >}}，其中 {{< math >}}p,q\in[1,\infty]{{< /math >}}。本文条件（2.3）要求

{{< math display="true" >}}\frac{Hd}{p}+\frac1q<1-H,\qquad p\ge 2Hd.{{< /math >}}

当 {{< math >}}p\le(1-H)^{-1}{{< /math >}} 且 {{< math >}}q>2{{< /math >}} 时，还要求

{{< math display="true" >}}\frac{Hd}{p}<\frac{p^{-1}-q^{-1}}{p^{-1}-1/2}\left(\frac12-H\right).{{< /math >}}

后两项条件用于支持 Girsanov 变换，不能仅凭第一条次临界不等式套用结论。

**主要结果。** 定理 2.1 证明强解存在，并给出逐路径唯一性。存在一个概率为一的噪声样本集合，对其中每条路径及每个初值，积分方程在沿解的漂移绝对可积的连续路径类中只有一个解。定理 2.6 构造半流，局部有界初值区域内，其起始时间和终止时间具有 {{< math >}}H-\varepsilon{{< /math >}} 阶 Hölder 控制，初值具有 {{< math >}}1-\varepsilon{{< /math >}} 阶控制。

**方法与证明思路。** 随机缝合引理控制沿高斯路径的加性泛函。作者结合粗糙路径方法处理解之间的线性化方程，并用消失平均振荡过程的定量 John–Nirenberg 不等式建立指数可积性与稳定性估计，再由近似构造半流。

**与研究主线的关联。** 分数噪声直接命中非马尔可夫过程主线，而对所有初值的共同逐路径唯一性与半流构造，将单个方程的适定性连接到随机动力系统。

**值得进一步研究的问题。** 本期提出，能否在保留半流结论的同时放宽用于 Girsanov 变换的附加可积性限制？这需要区分现有证明对这些条件的使用位置与方程本身的障碍。

## 本期观察

两篇都要求区分参数在结论中的作用。象随机游走的超扩散门槛与双峰门槛不同，分数方程的次临界条件与 Girsanov 所需条件也各有职责。将这些条件分别记录，更便于比较后续工作。
