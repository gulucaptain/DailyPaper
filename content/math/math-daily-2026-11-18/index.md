### Interacting Brownian Particles with Local Time Driven Jumps and Memory

{{< paper-meta
  authors="Flavio Argentieri、Gordan Žitković"
  source="arXiv 预印本"
  date="2026-11-15 · v1"
  arxiv="2611.20101"
  fulltext="https://arxiv.org/html/2611.20101v1"

  directions="非马尔可夫过程"
>}}

**研究问题与背景。** 粒子相遇的历史如何影响后续运动？本文让碰撞局部时增强跳跃强度，碰撞之间的强度则指数衰减，从而把近期相遇历史累积成一个动态记忆变量。

**核心模型。** 粒子在实线上进行布朗运动，并按自身强度发生跳跃。跳幅服从固定概率律，强度由与其他粒子的两两碰撞局部时激发。只观察位置时，未来还依赖过去碰撞留下的强度；联合观察位置和强度可保留这部分状态信息。

**主要结果。** 定理 2.1 对任意有限粒子数和非负相互作用强度，构造不爆炸且依分布唯一的系统。在 {{< math >}}N\gamma_N\to\kappa\ge0{{< /math >}} 的平均场缩放下，若初值可交换、具有混沌性，且初始强度族一致可积，则路径空间经验测度依概率趋于确定的极限律，任意固定数目的粒子联合律趋于该律的乘积。

**极限中的记忆。** 极限位置仍是布朗运动与强度驱动跳跃的叠加。记 {{< math >}}u(t,\cdot){{< /math >}} 为位置分布的密度，强度满足

{{< math display="true" >}}d\lambda_t=\bigl(\kappa u(t,X_t)-\lambda_t\bigr)\,dt.{{< /math >}}

这将其他粒子的碰撞输入替换为自身位置处的密度反馈。唯一性在论文定义的、平均强度局部有界的非线性过程类中成立。

**方法与证明思路。** 作者先建立强度和局部时的一致估计，再证明粒子及粒子对经验测度的紧性。识别极限时的关键是条件碰撞局部时，它在平均后变成沿轨道积分的位置密度。最后通过耦合证明非线性极限唯一性。

**与研究主线的关联。** 模型直接描述碰撞历史对未来跳跃的影响。平均场极限保留了强度记忆变量，使历史依赖机制与密度反馈同时出现在极限方程中。

**值得进一步研究的问题。** 本期提出，若将指数衰减替换为幂律衰减，能否仍建立路径空间的混沌传播？届时需要重新处理不能用单个强度变量闭合的记忆项。

### Local limit theorem for branching processes with immigration

{{< paper-meta
  authors="Sadillo Sharipov、Alexander Tarasov、Vitali Wachtel"
  source="arXiv 预印本"
  date="2026-11-14 · v1"
  arxiv="2611.19363"
  fulltext="https://arxiv.org/html/2611.19363v1"
  fulltextLabel="全文 v1"
  directions="分支过程"
>}}

**研究问题与背景。** 临界分支过程持续接受移民时，重标度种群已有 Gamma 分布极限。但这并不自动给出“第 {{< math >}}n{{< /math >}} 代恰有 {{< math >}}k{{< /math >}} 个粒子”的概率。本文证明，在适当规模区间内，只需后代有限方差和移民有限均值，就能得到局部近似。

**核心模型。** 过程满足

{{< math display="true" >}}Y_{n+1}=\sum_{j=1}^{Y_n}\xi_{n+1,j}+\eta_{n+1}.{{< /math >}}

后代变量独立同分布且均值为一，移民变量独立同分布，两族相互独立。论文假设后代律与移民律非周期。记后代二阶阶乘矩为 {{< math >}}B{{< /math >}}，移民均值为 {{< math >}}\lambda{{< /math >}}。以下讨论其非退化情形 {{< math >}}0<B,\lambda<\infty{{< /math >}}，并设 {{< math >}}\gamma=2\lambda/B{{< /math >}}。

**主要结果。** 定理 1 证明，存在趋于零的序列 {{< math >}}\varepsilon_n{{< /math >}}，使 {{< math >}}k\ge n\varepsilon_n{{< /math >}} 上的局部概率一致满足

{{< math display="true" >}}n\,\mathbb P(Y_n=k)\approx \frac{2}{B\Gamma(\gamma)}
\left(\frac{2k}{Bn}\right)^{\gamma-1}e^{-2k/(Bn)}.{{< /math >}}

这里“一致”指两边差的绝对值在该区域取上确界后趋于零。推论 2 进一步说明，当 {{< math >}}\gamma>1{{< /math >}}，可将区域扩展到所有非负整数。

**矩条件的作用。** 原文区分了正常偏差与较小种群规模。对于 {{< math >}}k=o(n){{< /math >}} 的下偏差，先前研究中可能出现非常数慢变因子。因此，定理 1 的结论应连同它给出的规模下界一起使用。

**方法与证明思路。** 作者将时间分成前期演化与末段过渡两部分，借助 Markov 性把总体局部概率写成条件过渡概率的平均。证明需要同时控制末段偏离主区域的概率，以及主区域内的局部近似，再与已知的分布极限衔接。

**与研究主线的关联。** 结果直接推进带移民临界分支过程的局部概率理论，明确了有限矩条件能支持的逼近范围，尤其适合与下偏差结果比较。

**值得进一步研究的问题。** 本期提出，能否从后代律和移民律的尾部定量确定 {{< math >}}\varepsilon_n{{< /math >}} 的可用下降速度，并估计一致近似误差？

## 本期观察

第一篇从带碰撞历史的有限粒子系统推导非线性极限，第二篇从分布极限进一步得到格点局部概率。两者分别提醒我们保留状态变量和规模区间，才能准确理解极限结论。
