### The elephant random walk with proportionally growing recent memory

{{< paper-meta
  authors="Hu, Zhishui、Xue, Shuwen"
  source="arXiv 预印本"
  date="2026-11-13 · v1"
  arxiv="2611.17664"
  fulltext="https://arxiv.org/html/2611.17664v1"
  fulltextLabel="全文 v1"
  directions="自相互作用随机游走、非马尔可夫过程"
>}}

**研究问题与背景。** 经典象随机游走均匀抽取全部历史步，再决定复制或反向。当记忆改成不断滑动的近期窗口，已有固定长度窗口的中心极限定理能否推广？本文处理窗口长度与总步数成正比的情形。

**核心模型。** 第一步在正负一之间等概率选择。第 {{< math >}}n{{< /math >}} 步从最近的 {{< math >}}m_n=\max\{\lfloor cn\rfloor,1\}{{< /math >}} 步中均匀抽取一项，以概率 {{< math >}}p{{< /math >}} 复制方向，否则反向。论文研究 {{< math >}}0<c<1{{< /math >}}、{{< math >}}0<p<1{{< /math >}} 的渐近行为，有限起始段按可用历史解释。位置记为 {{< math >}}S_n{{< /math >}}。

**主要结果。** 定理 1.2 给出临界点

{{< math display="true" >}}p_c(c)=\frac{3+\sqrt{1-c}}4.{{< /math >}}

- 当 {{< math >}}p<p_c{{< /math >}}，{{< math >}}S_n/\sqrt n{{< /math >}} 依分布趋于中心高斯，方差为有限正数。
- 当 {{< math >}}p=p_c{{< /math >}}，归一化改为 {{< math >}}\sqrt{n\log n}{{< /math >}}，极限仍为中心高斯，临界方差由定理给出。
- 当 {{< math >}}p>p_c{{< /math >}}，{{< math >}}S_n/n^\rho{{< /math >}} 几乎必然且在 {{< math >}}L^2{{< /math >}} 中趋于随机变量。其中 {{< math >}}\rho\in(1/2,1){{< /math >}} 是方程

{{< math display="true" >}}\rho=\frac{2p-1}{c}\bigl(1-(1-c)^\rho\bigr){{< /math >}}

的唯一正根。这里按本文定理保留其收敛表述。

**方差与记忆响应。** 扩散区间的方差可写为

{{< math display="true" >}}\sigma^2(c,p)=\int_0^\infty w(u)^2e^{-u}\,du,{{< /math >}}

其中 {{< math >}}w{{< /math >}} 是延迟微分方程的基本解，满足

{{< math display="true" >}}w'(t)=\frac{2p-1}{c}\bigl(w(t)-w(t+\log(1-c))\bigr),{{< /math >}}

并取负时间为零、零时刻为一的初始历史。记忆窗口因而通过一个确定性的延迟响应进入随机涨落。

**方法与证明思路。** 位置不能直接套用经典象随机游走的鞅归一化。作者将它表示成带确定性权重的鞅差三角阵列，通过连续插值研究权重，再将其与延迟方程的基本解比较。权重的增长决定方差累积尺度，随后应用鞅极限定理。

**与研究主线的关联。** 该模型直接研究历史依赖游走及其相变。临界点随 {{< math >}}c{{< /math >}} 增大而降低，在 {{< math >}}c\to1{{< /math >}} 时趋于经典阈值四分之三，在 {{< math >}}c\to0{{< /math >}} 时趋于一。这描述的是一族固定正比例窗口的临界点极限。

**值得进一步研究的问题。** 本期提出，如果窗口比例本身随步数趋于零，能否在固定比例窗口与固定长度窗口之间建立统一的极限理论？需要同时控制权重近似和随参数变化的延迟方程估计。

## 本期观察

这篇论文把记忆窗口的位置与长度都纳入模型。它的阈值公式适合与完整历史、远期历史和固定近期窗口的结论并列记录，比较时需保留各自的窗口增长假设。
