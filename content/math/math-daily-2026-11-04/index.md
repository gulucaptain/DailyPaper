### The Self-repelling Burglar

{{< paper-meta
  authors="Yaolin Yu"
  source="arXiv 预印本"
  date="2026-10-31 · v1"
  arxiv="2611.00854"
  fulltext="https://arxiv.org/html/2611.00854v1"
  fulltextLabel="全文 v1"
  directions="自相互作用随机游走、非马尔可夫过程"
>}}

**研究问题与背景。** 局部时剖面记录路径在各个位置积累的占用时间。给定整张剖面后，作者问终点还能落在哪些位置，以及这些位置的相对可能性。

**核心模型。** 从原点出发，研究具有联合连续局部时的多项式自排斥运动（PSRM）和真实自排斥运动（TSRM）。剖面的切点指支撑区间内部的零点。对有切点的 PSRM 剖面，可行区间由最外侧切点和同侧支撑端点围成。没有切点时，可行区间就是整个支撑区间。

**主要结果。** 定理 1.3 对任意参数 {{< math >}}\alpha>0{{< /math >}} 给出时刻 1 的条件律。设剖面为 {{< math >}}L_1{{< /math >}}，可行区间为 {{< math >}}I(L_1){{< /math >}}。终点在该区间内的条件密度正比于 {{< math >}}\sqrt{L_1(r)}{{< /math >}}，归一化常数是平方根剖面在可行区间上的积分。参数不显式出现在这一条件密度公式中。论文也为 TSRM 的已知 clever burglar 结论提供新证明。

**方法与证明思路。** 作者从逆局部时的 Ray–Knight 描述出发。PSRM 的空间剖面由经缩放的平方 Bessel 过程描述。适配这一空间过程的 Bismut 型分解帮助作者比较从不同终点观察同一剖面的权重。

**与研究主线的关联。** 自排斥留下的整张空间剖面会约束未来可行位置，也能反过来提供有关当前终点的信息。

**值得进一步研究的问题。** 本期提出，若只能观测有限网格上的局部时，切点附近的误差会怎样影响终点条件律？

### The Prodigal Elephant Returns: Last-Return Laws in the Superdiffusive Regime

{{< paper-meta
  authors="Hélio Trinas"
  source="arXiv 预印本"
  date="2026-10-31 · v1"
  arxiv="2611.01279"
  fulltext="https://arxiv.org/html/2611.01279v1"
  fulltextLabel="全文 v1"
  directions="自相互作用随机游走、非马尔可夫过程"
>}}

**研究问题与背景。** 超扩散象随机游走几乎必然只访问原点有限次。论文研究末次返回的尾概率，以及在很晚仍有返回的条件下，当前位置与后续返回时间如何共同变化。

**核心模型。** 一维最近邻游走从原点出发，每一步均匀抽取一个过去的增量，以概率 {{< math >}}p{{< /math >}} 复制，否则反向。令 {{< math >}}3/4<p<1{{< /math >}}、{{< math >}}a=2p-1{{< /math >}}，并令 {{< math >}}T_0{{< /math >}} 为最后一次位于原点的时刻。

**主要结果。** 定理 1.1 给出精确渐近式

{{< math display="true" >}}\mathbb P(T_0\ge n)\sim C_a n^{-(a-1/2)}.{{< /math >}}

其中 {{< math >}}C_a=f_a(0)\sqrt{8/(\pi(2a-1))}{{< /math >}}，{{< math >}}f_a{{< /math >}} 是首步为正时归一化位置几乎必然极限的密度。反射对称性使常数与首步偏置无关。固定非空有限目标集的末次访问具有同一尾渐近式。定理 1.2 进一步在晚返事件下给出位置、下一次返回及末次返回的联合弱极限。其中末次返回与下一次返回之比的极限，是标准反正弦变量的 {{< math >}}-1/(2a-1){{< /math >}} 次幂，且独立于另外两个极限坐标。

**方法与证明思路。** 作者按时刻 {{< math >}}n{{< /math >}} 的位置分解晚返概率。局部极限定理估计扩散窗口内的位置质量，未来路径的鞅归一化与时间变换给出返回核，晚期击中估计控制截断误差。

**与研究主线的关联。** 典型位置在超扩散尺度上，而晚返主要来自较窄的扩散窗口。这一尺度分离解释了为什么暂态仍可与很重的末返时间尾部共存。

**值得进一步研究的问题。** 本期提出，目标集扩大到扩散窗口同阶时，尾常数会如何依赖目标集的形状与位置？

### Local Limit Theorem for Branching Processes in Varying Environments

{{< paper-meta
  authors="Zhiyang Xia、Mei Zhang"
  source="arXiv 预印本"
  date="2026-11-01 · v1"
  arxiv="2611.01455"
  fulltext="https://arxiv.org/html/2611.01455v1"
  fulltextLabel="全文 v1"
  directions="分支过程"
>}}

**研究问题与背景。** 变环境分支过程中，生存概率及存活后的规模分布只描述总体行为。作者进一步估计第 {{< math >}}n{{< /math >}} 代人口恰好为整数 {{< math >}}k{{< /math >}} 的概率。

**核心模型。** 每一代有自己的后代生成函数。记 {{< math >}}Z_{i,n}{{< /math >}} 为从第 {{< math >}}i{{< /math >}} 代一个粒子产生的第 {{< math >}}n{{< /math >}} 代人口。记 {{< math >}}M_{i,n}{{< /math >}} 为这段期间后代均值的乘积，{{< math >}}a_{i,n}{{< /math >}} 为按环境均值加权的二阶阶乘矩累计尺度，定义见式 (1.5)。

**主要结果。** 定理 1.1 要求均值乘积统一有正下界和有限上界，二阶矩尾包络按权重 {{< math >}}(1+x)^{-1}{{< /math >}} 可积，以及后代律沿趋于无穷的代数取任何弱子列极限时具有正方差、正支撑最大公因数为 1。在这些条件下，正人口单点概率一致有 {{< math >}}C(n-i+1)^{-2}{{< /math >}} 上界。固定 {{< math >}}L_0>0{{< /math >}}，当 {{< math >}}n-i{{< /math >}} 和 {{< math >}}k{{< /math >}} 都趋于无穷且 {{< math >}}k\le L_0(n-i){{< /math >}} 时，有一致渐近式

{{< math display="true" >}}\mathbb P(Z_{i,n}=k)\sim\frac{M_{i,n}}{a_{i,n}^{2}}e^{-k/a_{i,n}}.{{< /math >}}

**方法与证明思路。** 作者先控制累计尺度和存活概率，再研究不同代的生成函数复合。统一尾包络控制二阶展开中的截断误差，正支撑公因数条件用于格点局部概率估计。

**与研究主线的关联。** 结果把临界型变环境分支的存活尺度和存活时人口尺度合在一个点概率公式里，还能同时比较不同起始世代。

**值得进一步研究的问题。** 本期提出，若弱极限具有非平凡格点周期，能否按可达剩余类写出相应的统一局部渐近式？

### Asymptotic behavior of some strongly critical decomposable multi-type Galton-Watson processes with immigration

{{< paper-meta
  authors="Mátyás Barczy、Dániel Bezdány"
  source="arXiv 预印本"
  date="2026-11-01 · v1"
  arxiv="2611.02069"
  fulltext="https://arxiv.org/html/2611.02069v1"
  fulltextLabel="全文 v1"
  directions="分支过程"
>}}

**研究问题与背景。** 多类型种群存在单向繁殖通道时，各类型即使都处在临界点，累积的上游输入也会让下游种群在更高的量级上增长。

**核心模型。** 考虑从零出发的可分解多类型 Galton–Watson 移民过程。后代均值矩阵下三角、对角线为 1。减去单位矩阵后得到严格下三角矩阵，其幂的非零元素编码跨类型繁殖链。第 {{< math >}}i{{< /math >}} 类的归一化指数 {{< math >}}\eta_i{{< /math >}} 为到达该类的最长链长度加一。

**主要结果。** 在定理 3.1 的矩阵条件和后代、移民有限二阶矩假设下，各类人口以 {{< math >}}n^{-\eta_i}{{< /math >}} 分别归一化，得到联合路径弱收敛。指数为 1 的坐标极限是独立的平方根扩散，漂移为该类移民均值，扩散强度由同类后代方差决定。高阶坐标则由这些扩散的迭代时间积分线性组合而成。例如二类型单向通道的尺度为 {{< math >}}n{{< /math >}} 与 {{< math >}}n^2{{< /math >}}，第二坐标极限是第一坐标的积分乘以跨类型后代均值。

**方法与证明思路。** 作者按繁殖链深度分解离散递推。源头类型的居中繁殖噪声产生扩散，沿通道累积的均值输入在缩放后成为时间积分。证明通过路径空间的收敛工具把这两步接起来。

**与研究主线的关联。** 极限结构把种群类型之间的依赖与各自的增长指数联系起来，也解释了下游共享同一个上游扩散时产生的相关性。

**值得进一步研究的问题。** 本期提出，当源头类型的后代方差无穷时，不同繁殖链深度对应的归一化和积分结构会怎样改变？

## 本期观察

本期的两个游走结果分别用空间局部时和未来返回核揭示历史依赖。两个分支结果关注不同的分辨率，一篇精确到单个整数人口值，另一篇保留整个多类型人口向量的时间演化。
