### What Does World Modeling Actually Improve in Robot Action Learning?

{{< paper-meta
  authors="Hanwen Cui、Yuanyuan Li、Qing Guo、Zhida Zhang 等"
  source="arXiv"
  date="2026-10-25 21:47 UTC · v1"
  arxiv="2610.34593"
  arxivURL="https://arxiv.org/abs/2610.34593"
  directions="世界动作模型、预测辅助监督、泛化评估"
  note="核验第3–6节、表1/4及局限；固定架构消融预测损失，全部RoboTwin 2.0仿真，单训练种子。"
>}}

**一句话总结：** 未来视频预测能改善熟悉任务上的动作学习，但不能把这种收益直接等同于稳健世界理解或分布外迁移。

**研究问题：** WAM成功率提高后，收益到底来自辅助训练目标、轨迹模式变化，还是能可靠迁移的物理建模能力？

**核心方法：** 在FastWAM和OpenWAM各自内部，固定架构、初始化、机器人数据、冻结配置与训练步数，只开关future-video prediction loss。随后分别检查干净已见任务、轨迹聚类、未见任务和环境随机化，并给π0.5添加仅训练时使用的视频预测分支。

**技术亮点：** 去掉预测损失不等于移除世界模型架构；两个模型家族的绝对分数也不能当作架构受控对比。实验把执行收益、行为统计和迁移能力拆成不同证据。

**实验结果：** 表1的十个Seen+Clean任务中，FastWAM和OpenWAM分别提高 **24.38、72.91个百分点**。π0.5加随机初始化的六层轻量Transformer预测器后，由 **82.94%升至89.19%**；Wan2.2-5B辅助分支为86.97%，不能据此声称大型生成器必需。未见任务收益不稳定，环境随机化下两者绝对成功率均很低，没有一致优势。

**应用场景 / 方向联系：** 适合选择VLA辅助训练目标，或检验世界模型是否真正带来跨任务和环境鲁棒性。

**研究价值与局限：** 控制变量设计很有价值，但WAM每配置只有一次训练，数千评估rollout不等于多训练种子复现。随机化结果还存在地板效应，无法区分预测监督不利于鲁棒性与模型整体能力不足；全部证据为RoboTwin 2.0双臂仿真，也未系统比较训练成本、显存和端到端时延。

### More Memory, Better Videos? A Controlled Study of Visual Memory in Long-Video Generation

{{< paper-meta
  authors="Yuzhuo Chen、Huafeng Shi、Xinyu Wang、Yulong Xu 等"
  source="arXiv"
  date="2026-10-26 08:13 UTC · v1"
  arxiv="2610.35001"
  arxivURL="https://arxiv.org/abs/2610.35001"
  links="[{\"url\": \"https://huggingface.co/papers/2610.35001\", \"label\": \"HF Papers\", \"kind\": \"huggingface\"}]"
  directions="长视频生成、视觉记忆、实体正确性"
  note="核验第3–4节、表3/4及附录H.3；HF于10月27日收录；同生成器比较完整检索策略，不是单帧替换因果实验。"
>}}

**一句话总结：** 长视频检索记忆能让旧实体更常回来，却也可能带回当前剧情已不该出现的对象或过时外观。

**研究问题：** 与历史画面更相似，是否就意味着更忠实于当前故事？仅测实体召回和身份连续性，可能漏掉记忆的副作用。

**核心方法：** VMem-Bench分两层：Track-A在92部电影、16,548个片段上诊断参考选择；Track-B对30个编写故事、2,824个片段，用共享生成器比较四种检索策略、无记忆与gold-informed last-seen控制，分别检查召回、精确率、禁止实体和外观时间有效性。

**技术亮点：** 将检索相关性与生成效用拆开，并剥离提示中的外观描述检查混淆：不使用视觉记忆也可能因为提示足够详细而实现长间隔实体回归。

**实验结果：** 同生成器下，检索使实体召回由 **0.559升至0.628–0.693**，精确率却由 **0.977降至0.915–0.938**；禁止实体规避由0.968降至0.845–0.898。它也可能强化故事变化前的旧外观。因此提高历史保真不自动意味着提高当前剧情正确性，范围对应不同检索策略，不能挑最好召回却忽略其对应代价。

**应用场景 / 方向联系：** 适合长视频记忆模块、角色一致性、故事状态维护和生成评估指标设计。

**研究价值与局限：** 给出了比“更多记忆更好”更细的评价框架。但每故事每条件只有一次生成；故事级置信区间不覆盖生成种子变化。各策略会形成不同后续历史，结果比较的是完整策略而非固定状态下换一张图的独立因果效应；gold控制的参考数也不等预算，绝对分数受MLLM裁判影响。

### Rethinking Verification in Agent Harnesses

{{< paper-meta
  authors="Zhengxin Zhang、Erkang Zhu、Yin Lin、Claire Cardie、Bolin Ding；Cornell University、Alibaba Group"
  source="arXiv"
  date="2026-10-25 21:17 UTC · v1"
  arxiv="2610.34577"
  arxivURL="https://arxiv.org/abs/2610.34577"
  links="[{\"url\": \"https://huggingface.co/papers/2610.34577\", \"label\": \"HF Papers\", \"kind\": \"huggingface\"}]"
  directions="AI Agent、独立审查、测试时计算"
  note="核验第3–5节、表2/3与附录A/C；HF于10月27日收录；成本含critic与修订，按论文固定API价计算。"
>}}

**一句话总结：** Agent验证应比较何时介入、谁检查、如何修订；独立critic在本研究中比反复要求自检有更好的平均成本收益。

**研究问题：** 更多“请再检查”可能增加工具调用与重复劳动，却不一定增加正确性。验证算力该放在哪个环节？

**核心方法：** 研究比较17种设计、七个编码模型，将验证分成初始指令、执行时提醒、完成门控和独立审查四层。独立critic读取工作区并自行检查，但无权改动交付物，再由主Agent依据反馈修订；同时使用编码基准子集与18任务VisualBench。

**技术亮点：** 成本包含主Agent、critic和后续修订，不只统计审查文本。还比较全轨迹与改动上下文、是否要求视觉检查，以及增加审查深度或宽度，避免把所有“验证”混作一个因素。

**实验结果：** 四种独立审查设计在Terminal-Bench的平均准确率提升 **5.9–9.5个百分点**，在SWE-bench Verified为 **3.9–6.6个百分点**；对应总成本为基线 **1.13–1.25倍、1.00–1.04倍**。这是模型平均与论文API价下的结果，不是每模型、任务都同等获益，也不是墙钟时间加速。VisualBench报告人类净偏好，不能与编码任务通过率混用。

**应用场景 / 方向联系：** 适合编码Agent脚手架、交付物质量检查，以及按预算选择验证介入点。

**研究价值与局限：** 为测试时验证提供可复用对照，但编码任务是经过选择的基准子集，critic固定为Qwen3.7-Plus，价格与模型组合会影响结论。VisualBench规模有限、由内部团队盲评；更多轮次并非对每个模型单调有益，结果不能直接作为所有Agent工作流的通用最优配置。

## 📊 今日研究趋势

**模块价值需要拆开度量。** 预测监督不等于大生成器的必要性，记忆相关性不等于剧情效用，验证次数也不等于交付质量。受控消融首先要说清楚到底改变了什么。

**平均收益不能遮住另一条轴。** 已见任务成功率之外要测分布偏移；实体召回之外要测误召回与过时外观；编码准确率之外要算审查和修订成本。

**证据范围应跟着结论走。** 单训练种子、单故事生成、固定critic与精选任务子集都影响可推广性。更多评估样本不能替代对训练、采样或系统配置的重复验证。

## 🏆 最值得关注的 3 篇

1. **What Does World Modeling Actually Improve in Robot Action Learning?**：适合设计WAM辅助目标消融，重点看控制变量和随机化地板效应。
2. **More Memory, Better Videos?**：适合长视频状态与记忆设计，同时比较实体召回、误召回和外观时效。
3. **Rethinking Verification in Agent Harnesses**：适合预算有限的Agent质量控制，先看任务选择、critic配置和完整成本口径。
